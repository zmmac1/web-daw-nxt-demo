What this is

One page that boots the real Tracktion engine (wasm, c39d5e32 — sha256 c39d5e32c8d9e380740cf1834657fa5921bb563827566b7bbc698ae4e1eed621), builds a musical 8-bar arrangement live (100 BPM, E minor), and lets you play it, tweak every surface, and run a measured verification suite — every control maps 1:1 to a real engine export.

Honest divergences (recorded, not hidden)

  • Live automation curve delivery: in a steady browser window, curve-active ≈ bypassed (§6j.6/§6i.2). The bounce composes the curve — the Analysis A/B is the audible leg.
  • Clip-gain sawtooth: a live clip-gain write class shows a restart sawtooth (§6g.4) — the gain slider is stopped-only.
  • Field names: the automation payload rides t / v / c (the worklet's reads) — the phase-exit demo's tSec/value/curve was a transcribed bug (R1-P0-4) and is NOT copied here.
  • Realtime safety: the browser's own output path can hide small glitches the engine's drop counters still see (and vice-versa for output-device dropouts) — V14 prints the caveat.

The arrangement

100 BPM · 8 bars · 19.2 s · E minor: Drums (4 wave-clip sections, last one carries a fill) · SYNTHS folder ⊃ Keys (sfizz EP, Em–C–G–D whole-bar pads + sparse top melody, 4bandEq with the −12 dB → 0 dB low-shelf curve, send → Reverb) + Bass (sfizz, roots + fifths) · Reverb bus (impulseResponse, synthesized 2.2 s IR) · Master (4bandEq mid-cut toggle).
